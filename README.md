# Kaldrivon Network Rescue — Kaldrivon Valley

A city-first browser game: inspect red buildings, choose an icon tool, fix the fault, then reconnect districts. Collect five energy stars for a perfect score. Seven missions, a weekly challenge, keyboard shortcuts, practice, optional sound, and device-local high scores.

Play: https://yoroyarell.github.io/KaldrivonNetworkRescue/

Static HTML/CSS/JavaScript. No dependencies, server, tracking, account, or live AI. GitHub Pages serves main at the repository root.

## Scoring
Inspect 150 + repairs 350 + district reconnection 200 + five stars 100 + speed up to 200. Wrong repairs cost 80 points and 20 health. A failed run is capped at 499. Practice has no timer and is not saved. Scores are stored in localStorage and can be cleared on the scoreboard.

## Assets
Original city illustration generated for this project. Kaldrivon logo from the Kaldrivon SMO site. Network behavior is synthetic and simplified.
